## 이직로그

이직로그는 이직을 준비하거나 직접 경험한 사람들이 익명으로 고민과 경험을 공유하는 커뮤니티입니다.
학생 개발자들이 기획부터 디자인, 프론트엔드와 백엔드까지 직접 만들어가고 있습니다.

## 프로젝트

| 저장소 | 설명 |
| --- | --- |
| [ijiklog-web](https://github.com/ijiklog/ijiklog-web) | 이직로그 웹 프론트엔드 |
| [ijiklog-api](https://github.com/ijiklog/ijiklog-api) | 이직로그 백엔드 API |

## 기술 스택

**Frontend** · Next.js · TypeScript · Cloudflare

**Backend** · NestJS · Prisma · PostgreSQL · Swagger

## 만들고 있는 기능

- 익명 기반 이직 경험 공유
- 게시글, 댓글, 공감과 북마크
- 검색, 정렬, 필터와 페이지네이션
- 알림, 신고, 차단과 관리자 운영 도구
- 이메일 인증과 안전한 세션 관리
